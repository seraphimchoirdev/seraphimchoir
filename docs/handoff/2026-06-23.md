## 8. Patterns & Conventions

- 사진 상호작용 API 경로: `/api/community/albums/[id]/photos/[photoId]/{reactions,comments,download}`
- 댓글 트리 조립: `createAdminClient`로 전체 조회(soft-deleted 포함) → parent/child Map으로 1-depth 트리 구성
- 토글 패턴: 좋아요는 INSERT→23505→DELETE, 반응은 SELECT 후 3-way(INSERT/DELETE/UPDATE)
- count 캐시: 트리거(`sync_*_count`)로 자동 동기화, 단 반응은 이모지별 집계라 GROUP BY 쿼리
- 외부 리소스 이름(버킷 등)은 반드시 상수로 정의 후 import (오타 방지)
- 모바일 오버레이 z-index: 라이트박스/시트는 `z-[var(--z-modal)]`(500) > 하단 네비(z-fixed=300)
