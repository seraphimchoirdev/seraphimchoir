## 1. Current State Summary

이미지 내보내기(export) 기능의 안정성을 집중적으로 개선한 날이다. 특히 갤럭시 폴드 등 대형/폴더블 기기에서 이미지 생성이 실패하는 문제와 빈 이미지가 생성되는 근본 원인을 수정했다. `toBlob` 실패 시 `toPng` fallback을 추가하고, user gesture 만료 대응, 행 레이블 레이아웃 버그 등도 함께 해결했다. 긴급 수정모드에 대원 목록 사이드바 숨기기 기능도 추가되었다.

Supabase Auth lock 경쟁 에러(race condition) 수정도 포함되어 있어, 동시 요청 시 인증 불안정 문제가 해결되었다.

## 5. Decisions Made

| 결정사항 | 이유 / 근거 | 대안 |
|---------|------------|------|
| `toBlob` → `toPng` fallback | 브라우저/기기별 API 지원 차이, fallback 없으면 공유 자체가 불가 | 단일 방식 강제 후 에러 안내 |
| 행 레이블 sticky 제거 | 스크롤 시 레이블 겹침 발생, sticky가 해당 레이아웃에 부적합 | z-index 조정으로 해결 시도 |
| 사이드바 숨기기 기능 추가 | 긴급 수정 시 화면 공간 확보, 대원 목록 불필요한 경우 많음 | 사이드바 너비 최소화 |

## 9. Potential Gotchas

- ⚠️ user gesture 만료 대응은 `setTimeout` 기반 — 매우 느린 기기에서 여전히 만료될 가능성 있음
- ⚠️ `toPng` fallback은 `toBlob` 대비 메모리 사용량이 높아 저사양 기기에서 OOM 위험 존재
- ⚠️ Auth lock 수정은 Supabase 클라이언트 레벨 처리 — Supabase SDK 버전 업그레이드 시 재확인 필요
