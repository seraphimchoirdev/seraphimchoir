## 2. Important Context

- **인쇄 가독성 문제**: 기존 좌석 카드는 진한 배경(600 레벨) + 흰 텍스트 조합으로, 흑백 인쇄 시 이름이 거의 안 보이는 문제가 있었음. 예배실에서 인쇄물로 줄 세우기에 사용하므로 가독성 필수
- **Turbopack 경고**: Next.js 16 + Sentry SDK 조합에서 deprecated 설정 경고가 콘솔을 오염시키고 있었음. `disableLogger`, `automaticVercelMonitors` 등이 webpack 네임스페이스로 이동해야 했음
- **seed.sql 문제**: 로컬 개발 시 `npx supabase db reset`이 빈 데이터로 초기화되어 매번 수동 데이터 입력이 필요했음. 프로덕션 데이터를 가져와 seed.sql로 변환하는 스크립트가 필요했음
