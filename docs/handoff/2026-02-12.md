## 8. Patterns & Conventions

- **시뮬레이션 패턴**: `simulate*` 함수는 실제 상태를 변경하지 않고 결과만 반환 — 미리보기용
- **줄반장 이관**: 같은 행 → 같은 파트 → 첫 번째 멤버 우선순위
- **React Query 캐시 키**: 날짜별 세분화 `['attendances', { date }]`
- **더블클릭 방지**: `useRef` + `isProcessingRef.current` 패턴 (useState보다 안전)

## 9. Potential Gotchas

- 크로스-행 이동 로직은 `simulateRemoveMember`와 실제 적용 로직 양쪽에 존재 — 한쪽만 수정하면 미리보기와 실제 결과가 불일치할 수 있음
- 줄반장 이관은 "같은 행 + 같은 파트"에 멤버가 없으면 이관하지 않음 (줄반장 없는 행이 될 수 있음)
