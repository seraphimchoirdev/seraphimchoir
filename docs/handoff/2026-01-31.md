## 8. Patterns & Conventions

- **캡처/인쇄 모드**: React prop 대신 CSS 클래스(`capture-active`) + `@media print`로 처리
- **data 속성 패턴**: `data-capture-target` (캡처 영역), `data-capture-ignore` (캡처 제외), `data-seat-slot` (좌석 CSS 타겟), `data-print-hide` (인쇄 시 숨김)
- **자동 문서화**: Git post-commit → `update-completed-docs.sh` → amend로 docs 포함

---

## 9. Potential Gotchas

- ⚠️ `update-completed-docs.sh`의 `--amend`는 `--no-verify`를 사용하므로 pre-commit 훅을 건너뜀 — docs만 추가하는 것이라 문제없지만 인지 필요
- ⚠️ 인쇄 모드에서 `capture-active` 클래스는 `requestAnimationFrame` 후 `window.print()` 호출 — `afterprint` 이벤트를 리스닝하지 않으므로 인쇄 취소 시에도 `classList.remove`는 동기적으로 실행됨
- ⚠️ `.sm\:flex` 같은 Tailwind 이스케이프 선택자는 `@media print` 내에서 사용 — Tailwind v4 빌드 후 실제 클래스명과 일치하는지 검증 필요
