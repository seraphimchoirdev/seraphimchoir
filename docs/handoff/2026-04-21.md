## 5. Decisions Made

| 결정사항 | 이유 / 근거 | 대안 |
|---------|------------|------|
| SECURITY DEFINER 트리거로 카운터 캐시 | RLS가 활성화된 테이블에서 트리거 내 UPDATE는 기본적으로 차단됨 — DEFINER 없으면 좋아요 수/댓글 수가 갱신 안 됨 | 매번 COUNT 쿼리로 실시간 집계 (성능 저하) |
| Cloudflare R2 (`@aws-sdk/client-s3`) | Supabase Storage 대비 대용량 미디어 비용 절감, S3 호환 API로 이식성 유지 | Supabase Storage 사용 |
| 커서 기반 무한 스크롤 | 오프셋 페이지네이션은 데이터 추가 시 중복/누락 발생, 커서 방식이 SNS 피드에 적합 | 오프셋 페이지네이션 |
| 앨범/투표는 스텁 페이지만 구현 | 이번 세션 범위 초과, 우선순위 낮음 — 라우트 확보 후 다음 세션에 구현 | 전체 구현 후 릴리스 |
| `scrollbar-hide` CSS 유틸리티 직접 추가 | Tailwind 4에서 플러그인 없이 커스텀 유틸리티 필요 | tailwind-scrollbar-hide 패키지 |

## 9. Potential Gotchas

- ⚠️ **SECURITY DEFINER 트리거**: 강력한 권한으로 실행되므로 트리거 로직 변경 시 보안 영향 검토 필수
- ⚠️ **R2 파일 업로드**: 클라이언트에서 직접 업로드 시 CORS 설정 필요 — R2 버킷 CORS 정책 확인 필요
- ⚠️ **TypeScript 6.0.3**: 일부 타입 추론 동작 변경 가능성 있음 — 빌드 에러 없이 통과했더라도 런타임 타입 이슈 모니터링 권장
- ⚠️ **미읽음 뱃지**: 실시간 갱신이 아닌 경우 폴링 또는 페이지 진입 시 갱신 방식인지 확인 필요
- ⚠️ **'기타' 카테고리**: 사용자 요청이 있었으나 결정 보류 — 다음 세션 시작 시 재확인 후 추가 여부 결정
- ⚠️ `e346f04`, `a51356c` 커밋은 이미 main에 반영됨 — 커뮤니티 브랜치 머지 시 충돌 없는지 확인
