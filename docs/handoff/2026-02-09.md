## 8. Patterns & Conventions

- **준비완료(Readiness) 패턴**: 파트별로 독립적 잠금, RLS 정책으로 삭제 권한 제어
- **블러 오버레이**: 잠긴 영역을 `backdrop-blur` + 반투명 오버레이 + 안내 텍스트로 표시
- **워크플로우 단계 순서**: 1(줄 구성) → 2(줄 정렬) → 3(AI 배치) → 4(수동 배치) → 5(줄반장) → 6(내보내기)
- **성능 패턴**: 폰트 로컬 호스팅 + preload, API 쿼리 Promise.all 병렬화, 레이아웃 단위 중복 제거
