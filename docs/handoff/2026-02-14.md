## 2. Important Context

- **getSession() vs getUser() 트레이드오프**: 이전 성능 최적화에서 TTFB 개선을 위해 `getUser()` → `getSession()`으로 변경했으나, Supabase SDK가 서버에서 `getSession()` 호출 시 무조건 보안 경고를 출력함. `getUser()`는 ~100-300ms 네트워크 호출이 발생하지만, Suspense 스트리밍 구조 덕분에 AppShell이 먼저 렌더되므로 체감 성능 영향 최소.
- **미들웨어 + 서버 컴포넌트 이중 검증**: 미들웨어에서 이미 `getUser()`로 인증을 검증하지만, 서버 컴포넌트에서도 `getUser()`로 재검증하는 것이 Supabase 공식 권장 패턴 (defense in depth).
