## 1. Current State Summary

자리배치(arrangements) 기능의 엣지 케이스 버그를 집중적으로 수정한 날이다. 긴급 수정 모드, 줄반장 수동 지정 모드, 배치표 상태 전환(SHARED↔DRAFT) 등 배치표 편집 흐름 전반에서 발생하던 7개 버그를 수정했다. 또한 예배 일정 정렬 시 같은 날짜 예배끼리 시작 시간으로 2차 정렬하는 로직도 추가했다.

## 9. Potential Gotchas

- ⚠️ `service_schedule_id` 누락 버그가 2곳에서 발견됨 — 긴급 등단 관련 다른 API 호출에도 같은 누락이 있는지 확인 필요
- ⚠️ 배치표 상태 머신(DRAFT/SHARED/CONFIRMED)이 복잡하므로, 상태 전환 로직 수정 시 전체 상태 다이어그램 참고 필수
- ⚠️ 새 배치표 생성 로직 변경으로 기존 배치표 데이터에는 영향 없으나, 재생성 시 줄 구성이 달라질 수 있음
